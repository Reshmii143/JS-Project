# Weather App - API Configuration

## 🔐 Безопасность API ключа

API ключ вынесен в отдельный файл `config.js`, который **добавлен в репозиторий**, чтобы демо на GitHub Pages работало. Ключ публичный — при желании замените его своим.

## 📋 Инструкция по настройке

### Шаг 1: Получите API ключ

1. Перейдите на [OpenWeatherMap](https://openweathermap.org/api)
2. Зарегистрируйтесь (бесплатно)
3. Получите свой API ключ в личном кабинете

### Шаг 2: Настройте приложение

1. Откройте `config.js` и замените текущий ключ на ваш API ключ:
   ```javascript
   const CONFIG = {
     WEATHER_API_KEY: "ваш_настоящий_api_ключ",
   };
   ```

### Шаг 3: Запустите приложение

- Откройте `index.html` в браузере
- Начните искать погоду!

## ⚠️ Важно!

- Файл `config.js` **находится** в git — ключ виден всем
- Не используйте здесь платный или важный ключ

## 📁 Структура файлов

```
06-weather-app/
├── index.html
├── scripts.js          # Основная логика
├── config.js           # API ключ (публичный, в git)
├── config.example.js   # ✅ Пример конфигурации (для git)
├── .gitignore          # Игнорирует .env и служебные файлы
└── .env.example        # Альтернативный пример
```

## 🚀 Как это работает

1. `config.js` содержит API ключ
2. `scripts.js` импортирует конфигурацию: `CONFIG.WEATHER_API_KEY`

## 🔄 Для других разработчиков

Если вы клонировали этот проект:

1. Просто откройте `index.html` — ключ уже в `config.js`
2. (Необязательно) замените ключ своим в `config.js`
